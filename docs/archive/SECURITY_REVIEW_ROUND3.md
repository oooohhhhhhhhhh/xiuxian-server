## ✅ 本轮修复内容

### 🔴 1. JWT系统全面重写
**文件**: `src/main/java/com/mtxgdn/util/JwtUtil.java`

**改动**:
- 新增 `init(boolean isInstallMode)` 方法，分两种模式初始化密钥
- **安装模式**: 自动生成临时密钥，安装向导完成后写入配置
- **生产模式**: 未配置 `jwt.secret` 时**拒绝启动**，抛出明确异常
- 新增密钥最小长度校验（32字节/256位）
- 新增 `warnIfAutoGenerated()` 启动后安全检查
- 新增 `getKeyFingerprint()` 安全状态显示（不暴露密钥）
- 新增 `isKeyConfigured()` 检查密钥是否为用户配置

**效果**:
- ✅ 未配置JWT密钥时服务器拒绝启动（非随机生成）
- ✅ 安装模式下自动生成临时密钥，安装完成后重启加载正式密钥
- ✅ 密钥长度不足时拒绝启动
- ✅ 启动后如有临时密钥发出强警告

---

### 🔴 2. 安装向导重写
**文件**: `src/main/java/com/mtxgdn/rest/InstallResource.java`

**改动**:
- 密码要求从6位提升到**8位**
- 新增管理员用户名格式校验（3-32位，正则验证）
- JWT密钥校验：用户提供密钥时最少48字节
- 自动生成密钥改为**64字节（512位）**，使用URL安全的Base64
- 新增 **`/api/install/reset`** 接口：支持已安装状态下重置（需提供当前管理员密码验证）
- 前端表单新增密码确认字段（adminPassword2）

**效果**:
- ✅ 安装安全性大幅提升
- ✅ 支持重置安装（需验证密码防未授权重置）
- ✅ 密钥强度从48字节提升到512位

---

### 🔴 3. 安装前端重写
**文件**: `src/main/resources/install/index.html`

**改动**:
- 密码最低长度从6位改为**8位**
- 新增**密码强度检测**（实时显示弱/中/强/极强）
- 用户名正则校验（3-32位）
- 新增密码确认字段
- JWT密钥提示升级：明确"留空自动生成（推荐）"
- JWT安全提示卡片：说明密钥作用和安全注意事项
- 环境检测显示JWT密钥指纹

**效果**:
- ✅ 引导用户设置高强度密码
- ✅ 提升用户对JWT密钥的安全认知

---

### 🟡 4. PVP次数持久化
**文件**: 
- `src/main/java/com/mtxgdn/db/DatabaseSchema.java` - 新增 `pvp_count` 列
- `src/main/java/com/mtxgdn/db/DatabaseMigration.java` - 迁移支持已有数据库
- `src/main/java/com/mtxgdn/game/service/CombatService.java` - 从内存改为数据库

**改动**:
- `player_daily` 表新增 `pvp_count INT DEFAULT 0` 列
- 删除内存态 `ConcurrentHashMap<Long, Integer>` 存储
- 新增 `getDailyPvpCount()` 从数据库读取今日次数
- 新增 `incrementDailyPvpCount()` 原子递增（跨天自动重置）
- 使用 `ON CONFLICT/ON DUPLICATE KEY` 保证并发安全

**效果**:
- ✅ 服务器重启后PVP次数不丢失
- ✅ 防止通过重启刷PVP次数
- ✅ 并发安全（原子操作）

---

### 🟡 5. Main.java集成
**文件**: `src/main/java/com/mtxgdn/Main.java`

**改动**:
- 启动时调用 `JwtUtil.init(installMode)` 初始化密钥
- 启动失败时输出明确错误信息并退出
- 服务器启动完成后调用 `JwtUtil.warnIfAutoGenerated()` 安全检查

**效果**:
- ✅ JWT密钥在服务器启动前正确初始化
- ✅ 未安装时使用临时密钥，安装后重启加载正式密钥

## 🛡️ JWT安全改进对比

### 修改前
```
❌ 未配置jwt.secret → 自动随机生成，重启失效
❌ 密钥长度无要求（1字节也可）
❌ 无法重置安装
❌ 无安全警告
```

### 修改后
```
✅ 未配置jwt.secret → 拒绝启动，明确报错
✅ 密钥最少32字节（256位），安装向导最少48字节（384位）
✅ 支持重置安装（需验证管理员密码）
✅ 自动检测临时密钥并发出强警告
✅ 显示密钥指纹（不暴露完整密钥）
✅ 安装向导自动生成512位高强度随机密钥
```
