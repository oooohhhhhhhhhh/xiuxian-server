# 归档文档（历史审计产物）

本目录存放项目历史上生成的**代码审查 / 安全审查 / 修复总结**类文档，仅供追溯参考。

> ⚠️ 这些文档写于 V1.4.1-beta1 / beta2 时期的某一轮审计，其中的版本号、文件路径、行号、
> 测试类名与"已修复"结论**不代表当前代码状态**，请勿作为开发依据。
> 当前有效的文档请见项目根目录的 [README.md](../../README.md)、[README_PLUGIN.md](../../README_PLUGIN.md)
> 与 [CHANGELOG.md](../../CHANGELOG.md)。
